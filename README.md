# НАІС Controller — оновлення

Публічний канал інсталяційних пакетів і описів версій НАІС Controller.
Вихідний код програми зберігається в окремому закритому репозиторії.

Програма перебуває в розробці. Готових перевірених інсталяційних пакетів
ще не опубліковано. Порожній розділ Releases не означає помилку оновлення.

Заплановані режими: ДРАЦС, НАІС АМТ, ІС ДП НАІС (РРП / ДРОРМ), ЄДРСР.

Після завершення перевірок розділ Releases міститиме Windows Setup EXE,
опис змін, контрольні суми та підписаний маніфест для оновлення з програми.
Не додавайте до issues паролі, ключі КЕП, дані пошуку або приватні документи.
