# НАІС Controller — інсталяція та оновлення

Вихідний код зберігається в окремому закритому репозиторії. Тут публікуються
інсталяційні пакети Windows, описи версій і підписані маніфести оновлень.

## Тестова збірка 0.1.1

[Завантажити Windows Setup EXE](https://github.com/morozyukvladislav-cell/nais-controller-releases/releases/download/v0.1.1/NAIS-Controller-0.1.1-Setup.exe)

[Зміни та межі готовності](https://github.com/morozyukvladislav-cell/nais-controller-releases/releases/tag/v0.1.1)

Це збірка для перевірки інтерфейсу, встановлення та оновлень. Повна робота
всіх чотирьох реєстрів ще не завершена. Стабільного випуску поки немає.

Потрібна Windows 10/11 x64. WebView2 встановлюється за потреби. Після
встановлення один раз завантажте розширення з папки `extension` усередині
папки програми через `chrome://extensions`. Після оновлення програми
перезавантажте картку цього розширення. Плагіни Codex залишаються окремо.

У вікні тестової програми позначено тестовий канал. Кнопка «Перевірити
оновлення» читає його підписаний маніфест; перед встановленням програма
перевіряє опис версії та інсталятор. Стабільний і тестовий канали розділені.
Початкову локальну збірку 0.1.0 потрібно один раз замінити цим інсталятором,
щоб підключитися до тестового каналу.

Маніфест підписано власним ключем оновлень програми. Цей підпис не є
Windows Authenticode: сертифіката видавця Windows у тестовій збірці немає.

Не додавайте до issues паролі, ключі КЕП, дані пошуку або приватні документи.
